# Third-party notices

PurrFind dynamically links to system libraries and does not vendor their source.

| Component | Purpose | Common license |
|---|---|---|
| Qt 6 | UI, D-Bus, image codecs, concurrency | LGPL-3.0-only/GPL/commercial |
| SQLite | local database and FTS5 | public domain |
| Poppler / Poppler-Qt6 | PDF extraction and rendering | GPL-2.0-or-later |
| Exiv2 | image metadata | GPL-2.0-or-later |
| Tesseract | local OCR | Apache-2.0 |
| Leptonica | OCR image processing | BSD-2-Clause |
| libzip | OOXML ZIP access | BSD-3-Clause |
| libxml2 | XML parsing | MIT |

Packages must comply with the exact library and trained-data versions they ship.
